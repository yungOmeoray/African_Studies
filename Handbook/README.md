# Handbook source

The ASEP Sprint content and its 1,000-question bank were prepared from the uploaded **INCOSE Systems Engineering Handbook, Fifth Edition (2023)**, supplied in these four parts:

1. `INCOSE_SEHB5_p1_A.pdf`
2. `INCOSE_SEHB5_p1_B.pdf`
3. `INCOSE_SEHB5_p2_A.pdf`
4. `INCOSE_SEHB5_p2_B.pdf`

The PDF binaries are intentionally excluded from application changes because the pull-request interface does not support binary-file diffs. Keep the source PDFs on the repository's handbook/source branch or upload them separately; do not add them to the web application PR.

The application's explanations, rapid-review notes, concept catalog, and question subject matter must remain grounded in this edition. Practice questions are original and are not represented as actual INCOSE examination questions.
